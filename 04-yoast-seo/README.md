# Yoast SEO

Yoast SEO is one of the most popular WordPress plugins for improving on-page SEO. It helps optimize your website for search engines by providing recommendations for content, metadata, readability, and technical SEO settings.

This section introduces the plugin, explains why it is widely used, and walks through the essential features you'll use when optimizing WordPress websites.

---

# What You'll Learn

By the end of this section, you should be able to:

- Install and activate Yoast SEO
- Complete the initial plugin configuration
- Optimize pages using a focus keyphrase
- Write effective SEO titles and meta descriptions
- Improve readability using Yoast's suggestions
- Configure XML sitemaps
- Understand canonical URLs
- Preview how pages appear on search engines and social media
- Avoid common SEO mistakes when using Yoast SEO
