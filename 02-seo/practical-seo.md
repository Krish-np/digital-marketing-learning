# Practical SEO

This section focuses on applying the SEO concepts covered in the guide. Instead of learning theory, you'll optimize real web pages, practice keyword research, and perform a basic SEO audit.

---

# Learning Objectives

By completing these exercises, you should be able to:

- Research keywords using free SEO tools
- Optimize a webpage for search engines
- Improve content readability
- Build an internal linking structure
- Create SEO-friendly titles and meta descriptions
- Generate an XML sitemap
- Configure a robots.txt file
- Perform a complete SEO audit

---

# Exercise 1 — Keyword Research

## Objective

Find a keyword that has search demand but low competition.

### Tools

- Google Search
- Google Trends
- Google Keyword Planner
- Ubersuggest (Free)

### Steps

1. Choose a topic.

Example:

```text
Digital Marketing
```

2. Search for related keywords.

Examples:

```text
digital marketing course
digital marketing in Nepal
learn digital marketing
```

3. Compare search interest using Google Trends.

4. Select one primary keyword and three supporting keywords.

# Exercise 7 — Create a robots.txt File

Create the following file.

```text
User-agent: *
Disallow: /admin/
Allow: /
```

Understand what each line does before using it on a live website.

# Exercise 8 — XML Sitemap

Visit your website.

If you're using WordPress with Yoast SEO, open:

```text
https://yourwebsite.com/sitemap_index.xml
```

Check whether:

- The sitemap loads successfully.
- All important pages appear.
- No unnecessary pages are included.

---

# Best Practices

- Write for people before search engines.
- Use keywords naturally.
- Avoid duplicate content.
- Keep URLs short and descriptive.
- Optimize images before uploading.
- Update old content regularly.
- Build backlinks naturally.
- Monitor website performance using Google Search Console and Google Analytics.
